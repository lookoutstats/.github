# Lookout

Vercel Web Analytics for every project, in one view.

[![Lookout: every Vercel project on one board, with drop alerts, a scorecard, a TV mode and a phone app](https://raw.githubusercontent.com/lookoutstats/.github/main/profile/lookout-demo.webp)](https://lookoutstats.com/demo)

▶ [Watch the 36-second video](https://youtu.be/J7yyrOE66DI)

Lookout reads the analytics Vercel already collects and puts all your projects on one board:
visitors, page views, pages per visit, Core Web Vitals and conversions, side by side.

- **Scorecard**: a grade from A to D for each landing page.
- **Fix list**: what to fix first on each board, ranked by visitors affected.
- **Flow**: which of your sites send visitors to which.
- **Share links**: read-only boards for clients, with no Vercel seat.
- **Alerts**: email and push when a site drops or spikes.
- **API and MCP**: ask about your analytics from Claude, Cursor or your own code.
- **Editor and terminal**: the open project's visitors and speed grade in VS Code or Cursor, and `npx lookoutstats` in a terminal or CI.

## Open source

- [lookout-dev](https://github.com/lookoutstats/lookout-dev): the extension for VS Code and Cursor ([Marketplace](https://marketplace.visualstudio.com/items?itemName=lookoutstats.lookout-vercel-analytics)) and the command line `npx lookoutstats` ([npm](https://www.npmjs.com/package/lookoutstats)). Read-only (MIT).
- [lookout-mcp](https://github.com/lookoutstats/lookout-mcp): the MCP server for Lookout (MIT).
- [lookout-skills](https://github.com/lookoutstats/lookout-skills): agent skills for Claude Code, Cursor, Codex and other agents (MIT).
- [lookout-starter](https://github.com/lookoutstats/lookout-starter): a Next.js template for Vercel, with Web Analytics, Speed Insights and conversion events set up (MIT).
- [vercel-analytics-api](https://github.com/lookoutstats/vercel-analytics-api): a typed client for the Vercel Web Analytics and Speed Insights API, with no dependencies (MIT).
